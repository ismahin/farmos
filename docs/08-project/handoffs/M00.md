## Important Interpretation Rule

Several M00 technical documents are intentionally **guardrails/working scaffolds**, not frozen implementation contracts. In particular, M00 does not freeze:

- backend language/framework
- physical database ERD/tables/IDs/indexes
- exact RLS SQL strategy
- REST/event/MCP payload schemas
- cloud/hosting vendor
- message broker transport
- exact SLO/latency/RPO/RTO values
- backup/retention periods
- mobile/offline client technology

M02 (Codex) must formally specify/freeze the appropriate architecture before M03 backend implementation.
