# ADR-0009 — UUIDv7 Identifiers

## Status
Accepted — 2026-09-22.

## Context
IDs must support offline/distributed creation, public APIs, debugging and PostgreSQL index locality without exposing row counts.

## Decision
Use RFC 9562 UUIDv7 in PostgreSQL `uuid` columns for entity/event/command IDs, generated by trusted application code or supported database functions. Use separate tenant-scoped human codes. IDs are opaque and never authorization evidence.

## Alternatives considered
- Integer sequences: compact/local but expose ordering/counts and complicate offline creation.
- UUIDv4: distributed but poorer index locality and time sorting.
- ULID/string prefixes: readable, but extra type/interoperability/canonicalization choices; M01 mock prefixes are not contracts.

## Consequences
Distributed generation and useful temporal locality with 16-byte indexes. Clock order is approximate, not a business timestamp; collision/format validation and secure authorization remain required.
